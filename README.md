# RIS 学习助手

基于 FastAPI、百炼模型接口、Chroma 和 SQLite 的本地网页问答项目。

支持普通聊天，以及根据自己上传的 PDF、TXT 资料进行知识库问答。
目前以 RIS（可重构智能表面）论文作为学习和验证资料。

## 功能

- 普通聊天：直接调用大模型回答。
- 知识库问答：检索已上传资料，结合原文生成回答并显示来源。
- 流式显示回答，支持停止生成。
- 选择或拖拽上传 PDF、TXT，支持一次选择多个文件。
- 查看已入库文件及切片数量。
- 从知识库删除指定文件对应的切片、原文和向量。
- 保存问答历史，查看最近10条记录，并删除指定历史记录。

## 工作流程

资料入库：

文件上传 → 提取文字 → 文本切片 → 生成向量 → 保存到 Chroma

知识库问答：

问题 → 生成问题向量 → 检索相关片段 → 拼接问题与资料
→ 调用大模型 → 流式回答 → 显示来源 → 保存问答历史

普通聊天直接调用大模型，不检索知识库。

## 环境与模型

当前开发环境为 Windows、Python 3.11，以下命令使用 PowerShell。

- 回答模型：qwen-flash
- 向量模型：text-embedding-v4
- 向量维度：1024
- 模型接口：百炼 OpenAI 兼容接口
- 向量数据库：Chroma
- 问答历史数据库：SQLite

需要配置可调用上述模型的百炼 API Key。
模型调用可能产生费用，以服务商账户的实际计费为准。

## 安装依赖

下载项目后，在项目根目录打开 PowerShell。

首次使用时创建虚拟环境；已有可用的 .venv 可以跳过：

```powershell
python -m venv .venv
```

安装依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 配置 API Key

执行以下命令，在输入提示处粘贴自己的 Key：

```powershell
$ragKey = Read-Host "请粘贴百炼 API Key" -AsSecureString
$env:DASHSCOPE_API_KEY = [System.Net.NetworkCredential]::new("", $ragKey).Password
```

Key 设置在当前终端环境中，不需要写入项目代码。
新开终端时需要重新设置。

## 启动

在配置 Key 的同一个终端执行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

浏览器访问：

http://127.0.0.1:8000/chat

保持终端运行；按 Ctrl+C 停止服务。

## 使用方法

### 普通聊天

选择“普通聊天”，输入问题并发送。
当前每次提问独立处理，不自动携带历史对话上下文。

### 知识库问答

1. 展开“知识库资料”。
2. 选择或拖入 PDF、TXT 文件。
3. 点击“上传并入库”，等待处理结果。
4. 在资料列表中检查文件名和切片数量。
5. 切换到“知识库问答”并提问。
6. 根据回答附带的文件名、PDF页码核对原文。

支持 UTF-8 编码的 TXT，每个文件不超过10 MiB。
PDF需要包含可提取的文字，暂不支持扫描图片的 OCR。

### 删除资料

点击文件旁的“从知识库删除”，确认后删除该文件的知识库记录。
后续检索不再使用这些记录。

此操作保留磁盘上的上传文件，也保留以前生成的问答历史。

| 文件 | 职责 |

## 本地数据

- knowledge_docs/uploads/：上传文件。
- knowledge_db/：Chroma 数据。
- chat_history.db：问答历史。

这些数据不随 Git 提交。
首次下载项目时知识库为空，需要自行上传资料。

## 当前限制

- 面向本地单人学习使用，尚未提供用户登录和权限管理。
- 暂不支持网址导入、自动联网搜索和扫描 PDF 的 OCR。
- 文本按字符长度切分，可能切断句子，公式和表格提取也可能不完整。
- 默认检索最近的3个片段，尚未加入相关性阈值和重排序。
- 检索结果不一定足以回答问题；来源清单表示检索到的资料，
  不保证模型的每个结论都有正确引用，需要核对原文。
- 重复上传同一文件仍会调用向量接口；相同切片 ID 会更新。
- 导入中途失败时，已经写入的批次会保留。
- 流式回答可以停止，但已发生的模型调用费用不会因此撤销。

- 知识库模式能够回答 RIS 基础问题并显示来源。
- 对资料未提供的个人信息问题，能够说明资料不足。
- PDF、TXT 上传及资料列表展示。
- 从知识库删除测试资料。
- 问答历史查询与删除。

这些是当前样例的检查结果，不代表所有问题都能准确回答。
